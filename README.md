# **CoreLesser**

一个尝试融合 **工业生产** **大战略** **即时战略** 玩法与机制的开源游戏项目。  
因为我找不到三者相对平衡的作品，所以创建此项目。

---

## 重要说明
### 默认分支（'main' / 'default'）
- **不包含任何实际代码**，仅用于项目介绍与记录每个分支的更新情况。  
- **请不要 fork 默认分支** 因为它没有可运行内容。
### 分支命名规则
所有代码分支以 'build-number' 格式命名（例如'buuild-1.0'、'build-1.5'、'build-2.0'）。  
数字递增，表示**递进但非兼容的重大更新**。

> **递进关系说明**  
> 例如：  
> 'build-1.0' 是原型验证版，缺少完整游戏功能.
> 当底层代码重构、依赖库变更（可能引发许可证变化）或架构不兼容时，会创建新分支如 'build-1.5' 或 'build-2.0'。
> **这意味着**：为 'build-1.0' 开发的模组、着色器、插件等，在 'build-1.5' 上可能完全无法使用，需要重写。

- 旧分支在新分支创建后**不在添加新内容**，但会永久保留（供研究参考或认为新版本仍未稳定继续游玩旧版本）。
- 社区内容开发者请根据目标分支的实际情况重新构建自己的项目。

---

## 分支与许可证

本项目**不是单一许可证**。
每个分支可能因为依赖的库不同，而采用不同的开源协议。
**请始终以你使用的分支根目录下的 'LICENSE' 文件为准。**

使用或基于任何分支的代码创建独立项目前，请务必阅读该分支的许可证。

---

### **为什么分支之间不兼容？**

### **因为游戏底层（如渲染管线、资源系统、网络同步等）可能被部分或完全重写，同时更换依赖库可能导致许可证冲突。为了让每个分支的法律状态和代码结构清晰，我选择创建全新分支而非继续叠加补丁。
